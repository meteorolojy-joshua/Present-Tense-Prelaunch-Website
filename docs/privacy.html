This notice covers the Present Tense prelaunch website. The app’s own storage and privacy arrangements are still being developed.

The waitlist

The waitlist is not connected yet. This website currently has no email collection form and does not store waitlist signups. When a signup form is connected, the website will link to it and the form’s own privacy information will explain where your details are stored, who can access them, and how to unsubscribe.

What a future signup is for

The planned waitlist is for development and launch updates, with optional interest in paid user testing. Joining will not guarantee access or a testing place, or commit you to participating. The testing format and compensation will be confirmed before you agree to take part. Please don’t submit app entries or personal experiences through a signup form.

The leaf demonstration

Edits to the example leaf stay in the current page while it is open. They are not sent to a server or saved in browser storage, and disappear when you reload or leave the page.

Website hosting

This website is hosted on GitHub Pages. GitHub logs visitors’ IP addresses for security purposes. See GitHub’s hosting information and privacy statement.

The app is still taking shape

Account syncing, device-only storage, and final platform support have not been settled. The intended core app experience does not require AI, and any future AI tools are intended to be optional. These plans are not promises about the prototype’s current data handling.
